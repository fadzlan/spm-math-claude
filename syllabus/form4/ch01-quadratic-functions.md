# Form 4, Chapter 1: Quadratic Functions and Equations in One Variable

## Overview

This chapter introduces quadratic expressions, quadratic functions, and quadratic equations in one variable. Core KSSM Mathematics work includes recognising their characteristics, interpreting a quadratic function as a many-to-one relation, investigating how `a`, `b`, and `c` affect the graph of `f(x) = ax² + bx + c`, forming a quadratic function from a situation, interpreting real roots, solving quadratic equations **by factorisation**, sketching graphs, matching graphs to functions, and solving suitable problems.

The quadratic formula, discriminant calculations, completing the square, vertex formula, roots-to-equation exercises, and formal optimisation are not core methods in this chapter. They must not be used to make a core question harder.

## Core conceptual notes

### Expressions, functions, equations, and roots

- `3x² - 5x + 2` is an expression.
- `f(x) = 3x² - 5x + 2` defines a function.
- `3x² - 5x + 2 = 0` is an equation.
- A real root `r` satisfies `f(r) = 0`, so `(r, 0)` is an x-intercept of the graph.
- A graph may cross the x-axis twice, touch it once, or not meet it. Describe this from the graph; do not require discriminant calculations.

### Many-to-one relation

A quadratic function can map different inputs to the same output. For example, `f(x) = x²` gives `f(-2) = f(2) = 4`. Question wording should say that a quadratic function is many-to-one over a typical real domain, not that every displayed pair of inputs must have equal images.

### Effects of coefficients

Use controlled comparisons in which only one coefficient changes.

- Compare `y = x²`, `y = 2x²`, and `y = -2x²` to investigate opening direction and width.
- Compare `y = x² + c` for several values of `c` to investigate the y-intercept and vertical position.
- Compare a small plotted family such as `y = x² + bx` for several values of `b` to investigate changes in position and symmetry.

Avoid teaching memorised vertex coordinates as the explanation for these effects. Any graph-matching item must have enough visible or stated features to give a unique answer.

## Solving by factorisation

Core solution pattern:

1. Rearrange so that one side is zero.
2. Factorise completely.
3. Set each factor equal to zero.
4. Solve both resulting linear equations.
5. Substitute into the original equation when verification is requested or when rearrangement was substantial.

Example structure:

`x² - 5x + 6 = 0`

`(x - 2)(x - 3) = 0`

Therefore, `x = 2` or `x = 3`.

For contextual questions, both algebraic roots must first be found. A root may be rejected only for a clear reason such as a negative length or violation of a stated interval.

## Sketching policy

Core sketches should be obtainable using a table of values and graph symmetry. Do not make use of `x = -b/(2a)`, completing the square, the discriminant, or calculus necessary.

For a sketching item:

- choose an x-range that shows the required features;
- include enough paired points to make the symmetry apparent;
- include `x = 0` so the y-intercept can be checked;
- use factorisable functions when real roots must be labelled;
- ensure the plotted curve passes through all generated points; and
- distinguish a rough mathematical sketch from an accurately plotted graph.

**No-real-root limitation:** for core items that ask learners to sketch a quadratic graph with no real roots, use only cases in which the maximum or minimum point lies on the y-axis. A suitable family is `f(x) = ax² + c`, with `a` and `c` having the same sign. Do not generate a no-real-root sketch with an off-axis turning point.

The number of roots may still be interpreted from a supplied graph with two intersections, one tangent point, or no intersection, provided no discriminant method is expected.

## Difficulty strategies

Difficulty must arise from reasoning, representation, or the amount of scaffolding, not from importing Additional Mathematics methods.

### Easy

- Recognise a quadratic among linear, cubic, or non-polynomial alternatives.
- State `a`, `b`, and `c`, including zero coefficients.
- State whether a graph opens upward or downward.
- Read a y-intercept or clearly marked real root.
- Solve a monic quadratic already equal to zero with small integer factors.

### Medium

- Rearrange an equation before factorising.
- Factorise a simple non-monic quadratic.
- Complete a value table and use equal output pairs to identify symmetry and a maximum/minimum point.
- Match functions to graphs using opening direction, intercepts, and relative width.
- Form a quadratic function from a stated product or rectangle situation.

### Hard

- Move between a situation, equation, factorisation, graph, and contextual conclusion with reduced scaffolding.
- Solve a multi-part problem whose quadratic is factorisable and whose roots require contextual validation.
- Compare several graphs where no single feature alone determines the match.
- Diagnose a plausible error in rearrangement, factorisation, zero-product reasoning, or root interpretation.
- Infer missing table entries or a coefficient from several consistent function values without using an out-of-scope formula.

## Common misconceptions and distractors

- Treating `a = 0` as quadratic.
- Confusing the constant term `c` with an x-intercept instead of the y-intercept.
- Assuming a parabola always has two real roots.
- Reading the root as the point `(r, 0)` when the question asks for the value `r`, or vice versa.
- Reversing the opening direction associated with the sign of `a`.
- Assuming a larger `|a|` makes the graph wider.
- Factoring correctly but setting only one factor equal to zero.
- Failing to rearrange the equation to zero before applying the zero-product property.
- Rejecting a negative algebraic root even when the context permits it, or retaining it when it represents a length.
- Drawing a curve that misses values in its own table.

Use a distractor only after confirming that it corresponds to a specific likely error and is not also mathematically valid.

## Visual aids

- Graph construction and graph-reading questions require a Cartesian grid or supplied graph.
- Every graph must be generated from the same function data used by the answer key.
- Store semantic data for the equation, plotted points, intercepts, maximum/minimum point, axis labels, scale, and intended x-range.
- Use equal axis spacing where visual comparison depends on shape; label non-unit scales explicitly.
- Do not rely on a near-scale decorative sketch to communicate exact roots or coordinates.
- A context diagram is optional and should be included only when it clarifies the variables or constraints.

## Generator notes and validation

- For a factorisable equation, choose valid factors first, expand independently for the prompt, then refactor or solve independently for validation.
- Permit repeated factors for one-real-root cases, for example `(x - p)² = 0`, while describing the single real root accurately.
- When selecting roots indirectly for internal generation, do not turn “form the equation from its roots” into a core learner task.
- Ensure every equation labelled quadratic has exactly one variable and a nonzero `x²` coefficient after simplification.
- For table-based questions, calculate every value from the stored function and check symmetry claims numerically.
- For graph matching, compare opening direction, y-intercept, real roots, and at least one additional point; reject ambiguous option sets.
- For context problems, encode domain constraints before sampling numbers and verify that exactly the intended root or roots satisfy them.
- Do not introduce denominators containing the unknown merely to disguise a quadratic; such rational equations are enrichment.
- Do not describe a question as frequent, high-weight, or tied to a particular paper section without a dated assessment corpus.

## Enrichment / Additional Mathematics boundary

The following may appear only when explicitly tagged `scope: enrichment` or `subject: Additional Mathematics`. They must not be prerequisites for, distractors in, or harder variants of core Mathematics questions:

- quadratic formula and irrational-root approximations;
- discriminant calculations, including parameter/equal-root equations;
- completing the square and vertex form;
- the formula `x = -b/(2a)` as a required method;
- forming a quadratic equation from prescribed roots as a learner skill;
- rational equations disguised as quadratics;
- deriving an equation from a vertex and a point;
- projectile-motion and revenue/profit models;
- formal maximum/minimum or optimisation problems, including fixed-perimeter area optimisation; and
- line-parabola intersection problems that require non-core methods.

An enrichment item must carry its scope label in both generation metadata and review output so it cannot enter a core Form 4 item pool accidentally.
