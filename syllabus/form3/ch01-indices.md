# Form 3, Chapter 1: Indices

## Overview
Formalises index (exponent) notation and the laws of indices, including zero, negative and fractional indices, and applies them to operations and problem solving. Same-base index equations are included only as an application of the laws; more advanced exponential equations are enrichment. Foundation for standard form (Ch2), quadratic manipulation, and all algebraic simplification in Forms 4–5.

## Prerequisites
Form 1 Ch3 (squares/cubes/roots); Form 2 Ch2 (algebraic manipulation); prime factorisation (Form 1 Ch2).

## Difficulty strategies

### 1.1
- **Easy**: evaluate small powers (2⁴, 5³); write 3×3×3×3 in index form.
- **Medium**: negative bases ((−2)⁴ vs −2⁴ distinction); fractional bases (½)³.
- **Hard**: combined with order of operations (2³ × 3² − 4²); compare values of powers (order 2¹⁰, 3⁶, 5⁴ by rewriting).

### 1.2 Laws
- **Easy**: single law, positive integer indices (x³ × x⁵; y⁸ ÷ y²).
- **Medium**: two laws combined ((a²b)³ ÷ ab⁴); zero and negative indices in answers ((x²)³ ÷ x⁸ = x⁻² = 1/x²); numeric with negative index (2⁻³, 5⁻² as fraction).
- **Hard**: fractional indices (8^(2/3), 32^(−3/5), (16/81)^(−1/4)); mixed laws with algebraic bases ((2x⁻²y)³ ÷ (4x²y⁻¹)); requiring final answer with positive indices only; nested powers ((x²)³)²; radical-index equivalence questions (√[3]{x²} = x^(2/3)).
- Distractors: aᵐ × aⁿ = aᵐⁿ (adding vs multiplying); (a + b)² treated as a² + b²; a⁰ = 0 error; a⁻ⁿ = −aⁿ error; misapplying (ab)ⁿ to (a + b)ⁿ.

#### Domain restrictions for generated items

- For zero and negative integer indices, require a ≠ 0: a⁰ = 1 and a⁻ⁿ = 1/aⁿ are not defined at a = 0.
- For a quotient, require every denominator to be nonzero; in particular, (a/b)ⁿ requires b ≠ 0, with any additional restrictions caused by n.
- Write a rational index m/n in lowest terms with n > 0. Over the real numbers, if n is even require a ≥ 0; if n is odd, a may be any real number. If m/n is negative, also require a ≠ 0 (so use a > 0 when n is even).
- When combining laws that involve fractional indices, use positive bases unless a negative-base identity has been checked separately; merely having both sides defined does not make every familiar power-law rewrite valid for a negative base.
- Do not generate an even root of a negative real number. For an algebraic base whose sign is not given, state the needed restriction rather than silently assuming it; alternatively choose a positive numerical base.
- Validate the original expression as well as the simplified answer. Cancelling or rewriting must not admit a value excluded from the original expression.

### 1.3 Index equations
- **Easy**: aˣ = aᵏ direct (2ˣ = 16).
- **Medium**: one-side conversion (9ˣ = 27 ⇒ 3^(2x) = 3³ ⇒ x = 3/2); products (3ˣ × 3⁴ = 3⁷).
- **Hard (core)**: several law steps followed by a same-base equation, with the unknown confined to one exponent; equations involving division may produce a negative exponent.
- Distractors: equating bases instead of indices; wrong prime-base conversion (9 = 3² not 3⁹); sign slips with negative exponents.

### Enrichment (not core Form 3 generation)

- Equations in which the unknown appears in exponents on both sides, for example 4ˣ = 8^(x−1).
- Growth or decay questions that require solving for the number of time periods. A context that merely interprets a given power remains suitable as a core application.
- Tag these items `scope: enrichment`; difficulty alone must never cause them to enter the core item pool.

## Generator notes
- Build Hard simplifications from a target single-term answer by reverse-applying laws, then verify numerically with random substitution.
- Fractional-index evaluation: choose bases that are perfect powers (4, 8, 16, 25, 27, 32, 36, 64, 81, 100, 125, 128, 144, 216, 243, 256, 343, 512, 1000), and check the real-domain conditions before accepting an item.
- Core index equations: generate a target value of x, place the unknown in one exponent, and disguise a numerical side using powers of the same positive base other than 1. Reserve equations derived from a relation such as 2x − 1 = x + 4 for enrichment because the unknown occurs on both sides after base conversion.
- Verify every generated equation by substitution into the original equation, not only the transformed exponent equation.
