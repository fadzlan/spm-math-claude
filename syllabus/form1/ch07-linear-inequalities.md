# Form 1, Chapter 7: Linear Inequalities

## Overview
Extends equations to inequalities: meaning of >, <, ≥, ≤; investigation and generalisation of inequality properties; solving linear inequalities in one variable and representing solutions on a number line; and simultaneous (combined) inequalities. Foundation for Form 4 Ch6 (inequalities in two variables).

## Prerequisites
Linear equations (Ch6); number line concepts (Ch1).

## Difficulty strategies

### 7.1
- **Easy**: write x > 5 from words; read inequality from a simple number line.
- **Medium**: "at least/at most/no more than" phrasing (traps: ≥ vs >); use numerical examples to investigate the converse, transitive or additive-inverse relationship; list integers in a range whose endpoint inclusion is stated explicitly.
- **Hard**: investigate the multiplicative-inverse relationship using positive values and explain why a set crossing zero needs separate care; decide whether a proposed generalisation is always true and give a counterexample when it is not; form an inequality from a word scenario with a limit.

### 7.2
- **Easy**: one step, positive coefficient (x − 3 > 2; 4x ≤ 20).
- **Medium**: two steps (3x + 5 < 17); negative coefficient requiring reversal (−2x ≥ 8 ⇒ x ≤ −4); represent on a number line with correct open/closed circle.
- **Hard**: variable both sides or brackets (2(3 − x) > x + 9); simultaneous inequalities solved separately then intersected ("2x − 5 ≤ 7 and 3x + 1 > 7"); express a bounded intersection as an equivalent chained inequality; list integer solutions from the intersection; word problems with constraints (maximum number of items within a budget).
- Distractors: failing to reverse sign; open vs closed circle; wrong intersection of two solution sets (union vs intersection).

## Generator notes
- Number-line convention: filled circle = included (≥/≤), hollow circle = excluded (>/<).
- Treat inequalities joined by **and** as an intersection of solution sets. A two-sided chained inequality such as 2 < x ≤ 6 is an equivalent compact representation of the intersection x > 2 and x ≤ 6; it is not a different set operation. Use **or** only when a union is intentionally in scope and label it clearly.
- For simultaneous inequalities, generate the two parts so the intersection is non-empty and, for "list all integer values" questions, contains a small number of integers (3–6).
- Before sampling or listing integers, resolve each bound and its endpoint status. For example, 2 < x ≤ 6 gives {3, 4, 5, 6}, whereas 2 ≤ x < 6 gives {2, 3, 4, 5}. Validate sampled values against every original inequality, not only the simplified chain.
- Generate property-investigation items from several valid numerical cases, followed by a requested generalisation or justification. For reciprocal comparisons, constrain both quantities to the same side of zero (preferably positive at this level); never generate zero as a denominator or assert that taking reciprocals always reverses an inequality without the needed domain condition.
- Keep algebraic transformations equivalent: apply the same operation to both sides, reverse the symbol exactly once when multiplying or dividing by a negative number, and verify the final solution with one satisfying and one non-satisfying test value away from an open endpoint.
- Integer-listing questions are extremely common in SPM; always make them available at Medium+.
